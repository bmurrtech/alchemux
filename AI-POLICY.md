# AI Policy

This project accepts AI-generated pull requests when the following guidelines are met.

## Requirements

1. The pull request must fill in the repository's pull request template.
2. The pull request must identify itself as AI-generated and disclose:
   - **Harness used** — e.g. Codex, Claude Code, OpenCode, Cursor, Pi
   - **Primary model used to write code** — e.g. Opus 4.8, GPT-5.6, GLM-5.2, Kimi K2.6
3. The pull request must link to an issue or discussion where a solution has been approved by a maintainer/owner.

## Example disclosure (PR body)

```markdown
## AI assistance
- Agent: Cursor
- Primary model: GPT-5.6 Sol
```

## Enforcement

The maintainer reserves the right to close PRs without comment if the above are not met.

See also: [CONTRIBUTING.md](CONTRIBUTING.md).
